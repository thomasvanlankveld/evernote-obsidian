# Agents: EDDs in this folder

When a branch **finishes an EDD phase**: run **`npm test`** (and **`npm run build`** / **`npm run lint`** if you changed code), then update the **matching EDD** here (checkboxes + **Last updated**) on the **same branch** before pushing or marking the PR ready.

Individual EDDs may repeat a short “EDD phase completion” note at the top for human reviewers; this file is the canonical checklist for agents.
